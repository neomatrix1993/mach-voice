# Fix microphone problems

Use this guide when Mach enters the listening state but captures no speech, or
when dictation does not begin because microphone access is unavailable.

## Allow microphone access

1. Open **System Settings → Privacy & Security → Microphone**.
2. Turn Mach on.
3. Quit and reopen Mach after changing the permission.
4. Try one short dictation.

## Check the selected microphone

1. Open Mach and choose **Dictation Settings**.
2. Select the microphone you are speaking into.
3. Confirm that an external microphone or headset is connected and not muted.
4. Speak close to the selected device and retry.

## Separate possible causes

- If other Mac apps also receive no audio, check the device and macOS settings.
- If Mach never shows the listening state, check the configured shortcut and
  restart Mach.
- If audio is captured but no result returns, use the
  [connection guide](connection.md).

Restart the Mac once after confirming permission if the problem remains. Then
contact [Mach Support](https://usemach.app/support) with your macOS version and
microphone model.
