# Fix update problems

Mach normally checks for updates about once per day. Available updates can
download in the background and install when Mach quits.

## Check immediately

1. Open Mach.
2. Choose **Check for Updates…**.
3. Follow the visible update instructions.
4. Quit and reopen Mach when prompted.

Relaunching alone does not force another scheduled check. Use **Check for
Updates…** when you want an immediate result.

## Install a fresh copy

If the update still does not appear, download the current installer from
[usemach.app/download](https://usemach.app/download). Quit Mach before replacing
the app in Applications.

After reinstalling or moving the app, macOS can ask you to confirm Microphone,
Accessibility, or System Audio Recording access again.
