# Fix text-pasting problems

Use this guide when dictation finishes but the result does not appear in the
focused app.

## Allow Accessibility access

1. Open **System Settings → Privacy & Security → Accessibility**.
2. Turn Mach on.
3. If Mach appears more than once, remove old entries and enable the current app.
4. Quit and reopen Mach.

## Test a simple destination

1. Open TextEdit and create a blank document.
2. Click inside the document so the insertion cursor is visible.
3. Make one short dictation.
4. If it appears in TextEdit, retry in the original app and confirm that its
   field is editable.

## Expected limitations

- Password and other secure fields can block automatic insertion.
- Some apps require a normal editable field to have focus.
- Accessibility permission can need to be granted again after reinstalling or
  moving the Mach app.

Restart Mach and the destination app if TextEdit also fails. Contact
[Mach Support](https://usemach.app/support) and mention whether the dictation
overlay completed successfully.
