# Troubleshoot Mach

Start with the symptom that best matches what you see.

| Symptom | Guide |
| --- | --- |
| Mach opens but cannot hear speech | [Microphone problems](microphone.md) |
| Dictation finishes but text does not appear | [Text-pasting problems](text-pasting.md) |
| Dictation cannot start, connect, or finish | [Connection problems](connection.md) |
| Mach does not update as expected | [Update problems](updates.md) |
| Live Translate has no source, translation, or access | [Live Translate problems](live-translate.md) |

## Fastest general checks

1. Confirm your Mac has a working internet connection.
2. Confirm Mach is signed in and enabled.
3. Review the required permission in **System Settings → Privacy & Security**.
4. Open Mach and choose **Reset Connection**.
5. Try a short dictation in a blank TextEdit document.
6. Quit and reopen Mach only if the focused check did not help.

## Contact support

Visit [Mach Support](https://usemach.app/support) when the problem continues.
Include your macOS and Mach versions, the app or audio source involved, what you
expected, what happened, and the approximate failure time when relevant.

Do not include passwords, authentication tokens, private dictated text,
customer data, or other sensitive content.
