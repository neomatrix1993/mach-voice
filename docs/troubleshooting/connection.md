# Fix connection and unfinished dictations

Mach needs an internet connection. Use these steps when a dictation cannot
start, repeatedly stops, or never returns text.

## Reconnect Mach

1. Confirm that another website loads on your Mac.
2. Open Mach.
3. Choose **Reset Connection**.
4. Wait a moment, then try one short dictation.

## Relaunch only if needed

1. Quit Mach completely.
2. Reopen it from Applications.
3. Confirm that you are still signed in.
4. Try a short phrase in TextEdit.

Mach keeps overlay errors short and actionable. Internal server addresses and
technical provider messages should not appear there.

If other websites work but Mach repeatedly cannot connect, contact
[Mach Support](https://usemach.app/support). Include the approximate failure
time, your macOS and Mach versions, and whether **Reset Connection** changed the
result. Do not include private dictated content.
