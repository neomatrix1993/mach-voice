# Mach language support

Mach offers 87 language and regional dictation options. Choose the most
specific option that matches how you speak. The list below reflects Mach 1.1.2;
check the [Help Center](https://usemach.app/help/supported-languages) for the
current catalog.

## Multilingual mode

Multilingual mode automatically preserves code-switching between:

- English
- Spanish
- French
- German
- Hindi
- Russian
- Portuguese
- Japanese
- Italian
- Dutch

You do not need to preselect a pair. A German phrase stays German and an English
phrase stays English. For languages outside this set, choose a single-language
option and change the selection between dictations.

## Original script or Latin output

Mach keeps the original writing system by default. When **Writing style**
appears for the selected language, Refined mode can write it with readable
Latin letters instead.

In Multilingual mode, the available choices include:

- Hindi as Hinglish;
- Japanese as Romaji; and
- Russian with experimental Latin output.

Romanization changes the writing system, not the language or meaning. Languages
already written with Latin characters remain as spoken. Verbatim mode keeps the
speech-recognition output without AI romanization.

## Choose the best setting

- Use a focused language for single-language speech.
- Choose the closest regional option when one is available.
- Use Multilingual only when you actually switch among its ten languages.
- If an entire result appears in the wrong language, choose the exact focused
  language and try a short dictation again.
