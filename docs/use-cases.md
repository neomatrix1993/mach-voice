# Ways to use Mach

Mach works best when speaking is faster than typing and the finished result
still needs to be clear, structured, and ready for the current app.

## Everyday writing

Use Refined dictation to draft:

- email replies and follow-ups;
- chat messages and status updates;
- meeting notes and action items;
- project plans, checklists, and briefs; and
- longer thoughts that are easier to explain aloud.

Name groups, owners, and ordering while you speak. Mach can turn those verbal
cues into paragraphs, bullets, and numbered lists. See the
[before-and-after examples](examples.md).

## Developer workflows

Mach can help with the communication around software work:

- dictate detailed prompts for coding agents;
- explain observed versus expected behavior while debugging;
- capture reproduction steps and important evidence;
- draft issues, review notes, release summaries, and team updates; and
- speak filenames and nested paths in supported app contexts.

A useful coding-agent prompt contains four parts: the outcome, relevant context,
constraints, and verification. Dictate intent and trade-offs, but type exact
code, commands, regular expressions, secrets, and short identifiers.

Read the canonical [developer workflow](https://usemach.app/use-cases/developers).

## Multilingual work

Use a focused language when one language is enough. Use Multilingual mode when
you naturally switch between supported languages inside the same thought.

Optional Latin output can make selected writing systems easier to share in a
Latin-character workflow. For example, Hindi can be written as Hinglish and
Japanese as Romaji without translating the meaning.

See the [language reference](languages.md) for the supported catalog and limits
of Multilingual mode.

## Hands-free capture

Press `Fn + Space` to start and stop a longer dictation without holding a key.
This works well for outlining, reflective notes, project recaps, and longer
prompts. Press `Esc` to cancel without inserting text.

## Live translation

Live Translate helps you understand audio already playing on your Mac. It works
beside the conversation instead of joining as a meeting bot.

![Mach Live Translate beside a multilingual meeting](https://usemach.app/live-translation/use-cases/meetings-live-translation.webp)

Common workflows include:

- [meetings and calls](https://usemach.app/use-cases/live-translation/meetings-and-calls);
- [interviews and research](https://usemach.app/use-cases/live-translation/interviews-and-research);
- [videos and live streams](https://usemach.app/use-cases/live-translation/videos-and-live-streams);
- [lectures and training](https://usemach.app/use-cases/live-translation/lectures-and-training);
- [customer support](https://usemach.app/use-cases/live-translation/customer-support); and
- [German official calls](https://usemach.app/use-cases/live-translation/german-official-calls).

Confirm important legal, medical, financial, or official details with the
original speaker or institution.

## Know when to type

Use the keyboard when exact characters matter more than speed. Always type and
protect passwords, API keys, authentication tokens, private customer data, and
other secrets. Review destructive, billing, legal, security, medical, financial,
and production instructions before acting on them.
