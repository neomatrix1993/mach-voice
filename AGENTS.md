# Repository guidance

- Keep this repository focused on public Mach documentation.
- Write clear, concise Markdown and link product information to
  [usemach.app](https://usemach.app).
- Keep privacy and security wording consistent with the canonical policies on
  the Mach website.
- Never add credentials, private customer data, or proprietary application code.
- Use conventional branch prefixes such as `docs/`, `feat/`, `fix/`, and
  `chore/`; do not use tool or agent names as branch prefixes.
- Check formatting and relative links before committing documentation changes.
